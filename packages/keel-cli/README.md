# keel-cli

The `keel` command.

| Command | Status |
|---|---|
| `keel init [DIR]` | Works. Creates a starter `keel.yaml` with secure defaults. |
| `keel diff OLD NEW` | Works. Shows which settings changed. `--exit-code` fails on any change. |
| `keel dev` | Not implemented yet |
| `keel eval` | Not implemented yet |
| `keel promote` | Not implemented yet |
| `keel audit` | Not implemented yet |

Commands that are not built yet exit with code 2.

Status: pre-alpha.
