# 1. Record architecture decisions

Date: 2026-11-16

## Status

Accepted

## Context

Keel makes many design choices early, and later contributors need to know why.

## Decision

Record each significant decision as a short Markdown file in `docs/adr/`, numbered in order.
Each record has a context, a decision and its consequences. A record is never edited after it is accepted.
A later record supersedes it instead.

## Consequences

Decisions stay visible and reviewable in pull requests. Writing a record takes a few minutes per decision.
