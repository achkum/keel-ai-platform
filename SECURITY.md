# Security policy

Keel is pre-alpha and not ready for production use.

## Reporting a vulnerability

Please do not open a public issue for security problems.
Report them privately through GitHub's [private vulnerability reporting](https://github.com/achkum/keel-ai-platform/security/advisories/new).

You can expect an acknowledgement within 7 days. Please include steps to reproduce and the affected version or commit.

## Threat model

Security controls are designed against the OWASP Top 10 for LLM Applications 2026 and the OWASP Top 10 for Agentic Applications 2026.
